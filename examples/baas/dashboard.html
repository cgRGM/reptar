Architecture Highlights

PocketBase / Convex Alternative
Zero Runtime Reflection: Compiled for Native AOT and NetWasm with stack-allocated column tokens (ColumnRef<T>) preventing typos before runtime.
Magic-Byte Sniffing: File uploads inspect raw file signatures (PNG, JPEG, WebP, PDF) to stop spoofed MIME attacks with zero heap overhead.
Instant SSE Feeds: Mutations broadcast over server-sent events directly to subscribers with automatic 15-second heartbeat keepalives.
