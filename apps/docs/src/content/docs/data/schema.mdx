## Column Types & Modifiers

Reptar provides column definitions tailored to SQLite and Cloudflare D1:

- `Col.Text(columnName)`
- `Col.Int(columnName)`
- `Col.Real(columnName)`
- `Col.Blob(columnName)`

### Modifiers

- `.PrimaryKey()` — Marks the column as primary key.
- `.NotNull()` — Sets a NOT NULL constraint.
- `.Unique()` — Adds a UNIQUE constraint and generates an index.
- `.Indexed()` — Generates an explicit index.
- `.Default(value)` — Sets a constant default value.
- `.DefaultSql("CURRENT_TIMESTAMP")` — Sets an SQL-evaluated default expression.
- `.References(foreignTable, foreignCol, onDelete)` — Declares a foreign key relationship.

## Aggregation (`apps/api/schema/index.cs`)

You can explicitly aggregate tables or allow build-time discovery to find every `TableDef` across partial classes:

```csharp
public static partial class Schema
{
    public static readonly TableDef[] All = [Users, Posts];
}
```
