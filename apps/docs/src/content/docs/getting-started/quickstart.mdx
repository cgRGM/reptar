## Prerequisites

Before starting, ensure you have the following installed:

- **.NET SDK 10.0+** (used as a compiler/build toolchain; never required at runtime in production)
- **Bun 1.3+** or **Node.js 22+**
- **Cloudflare CLI (`cf`)** (or Wrangler for existing Wrangler projects)

## 1. Scaffold a New Project

Initialize a fullstack monorepo with a C# Reptar backend, generated TypeScript RPC client, and your frontend of choice:

<Tabs syncKey="pkg">
  <TabItem label="bun">

### Workspace Structure

```text
my-app/
├── apps/
│   ├── web/               # Frontend app (React 19 / Astro / TanStack Start)
│   └── api/               # Reptar C# backend (Cloudflare Workers Wasm & Native AOT)
├── packages/
│   ├── client/            # Zero-dependency typed RPC client (@reptar/client)
│   └── rpc/               # Generated AppType, DTO interfaces, and OpenAPI 3.1 spec
└── scripts/
    └── reptar.ts          # Dev runner, contract codegen, and CLI migration engine
```

## 2. Application Composition (`apps/api/app.cs`)

Your backend entry point configures database drivers, middleware, interactive OpenAPI documentation, and route slices:

```csharp
var authOptions = new AuthOptions
{
    CookieName = "better-auth.session_token",
};

var app = ReptarApp.Create(new ReptarConfig
{
    Auth = authOptions,
    Database = Db.D1(), // or Db.Sqlite("app.db") / Db.Postgres(url) / Db.MySql(url)
});

// Core observability, caching, and rate-limiting middleware
app.Use(RequestId());
app.Use(Telemetry());
app.Use(Cors());
app.Use(CacheControl.SWR(ttlSeconds: 15, swrSeconds: 30));
app.Use(RateLimit.SlidingWindow(limit: 120, windowSeconds: 60));

// Serve OpenAPI 3.1 at /openapi.json and interactive Scalar docs at /reference
app.UseScalar(title: "My Reptar API", version: "1.0.0");

// Mount Better Auth endpoints under /api/auth
var authGroup = app.Group("/api/auth");
BetterAuthProtocol.Routes(authGroup, authOptions);

// Mount domain feature slices
ItemsFeature.Configure(app);

await app.EnsureCreatedAsync();
await app.RunAsync(args);
```

## 3. Run Database Migrations

Create and apply sequential SQL migrations using the built-in CLI runner:

```bash
# Check applied and pending migrations
bun scripts/reptar.ts db status

# Scaffold a new sequential SQL migration file
bun scripts/reptar.ts db new add_items_index

# Apply pending migrations transactionally
bun scripts/reptar.ts db migrate
```

## 4. Start Local Development

Run the fullstack development server:

```bash
bun run dev
```

This starts:

- The Reptar C# API backend at `http://localhost:8787`
- Interactive Scalar API Reference at `http://localhost:8787/reference`
- The frontend application at `http://localhost:5173` (or `http://localhost:4321`)

## 5. Generate & Consume Typed Contracts

Whenever you add or modify C# routes, regenerate the TypeScript RPC contracts:

```bash
bun run api:codegen
```

Consume your backend from any TypeScript frontend with full autocomplete:

```tsx
import { createClient } from "@reptar/client";
import type { AppType } from "@reptar/rpc";

export const api = createClient<AppType>("http://localhost:8787", {
  credentials: "include",
});

const response = await api.items.$get();
if (response.ok) {
  const items = await response.json();
}
```
