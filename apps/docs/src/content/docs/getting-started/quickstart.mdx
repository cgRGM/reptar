## Prerequisites

Before starting, ensure you have the following installed:

- **.NET SDK 10.0+** (used as a background build tool)
- **Node.js 22+** or **Bun 1.3+**
- Your preferred package manager: **npm**, **pnpm**, **yarn**, or **bun**
- **Cloudflare CLI (`cf`)** or Wrangler

---

## 2. Project Composition (`apps/api/app.cs`)

Your entire application entry point is configured in `app.cs`:

```csharp
var app = Reptar(new ReptarConfig
{
    Database = D1(),
    Storage = R2(),
    AI = WorkersAI(),
    Auth = BuiltIn(new AuthOptions
    {
        SessionDays = 30,
        AllowAnonymous = true
    }),
    Telemetry = Axiom()
});

app.Use(RequestId());
app.Use(Telemetry());
app.Use(Cors());

app.RegisterSchema(Schema.All);

app.Route("/auth", Reptar.Auth.Routes());
app.Route("/posts", Posts.Routes());

await app.RunAsync(args);
```

## 3. Local Development

Run the unified development environment:

<Tabs syncKey="pkg">
  <TabItem label="npm">```bash npm run dev ```</TabItem>
  <TabItem label="pnpm">```bash pnpm dev ```</TabItem>
  <TabItem label="yarn">```bash yarn dev ```</TabItem>
  <TabItem label="bun">```bash bun run dev ```</TabItem>
</Tabs>

This starts:

- Local SQLite database emulation for `c.Db`
- The TypeScript host shim watching for C# recompilation
- The local frontend at `http://localhost:4321`

## 5. Consume from the Frontend

Install the typed client in your frontend:

<Tabs syncKey="pkg">
  <TabItem label="npm">```bash npm install @reptar/client ```</TabItem>
  <TabItem label="pnpm">```bash pnpm add @reptar/client ```</TabItem>
  <TabItem label="yarn">```bash yarn add @reptar/client ```</TabItem>
  <TabItem label="bun">```bash bun add @reptar/client ```</TabItem>
</Tabs>

Import the generated client in your frontend code:

```ts
import { createClient } from "@reptar/client";
import type { AppType } from "@reptar/rpc";

const api = createClient<AppType>(import.meta.env.VITE_API_URL);

// End-to-end typed request
const posts = await api.posts.$get();
console.log("Fetched posts:", posts);
```
