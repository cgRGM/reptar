## Prerequisites

Before starting, ensure you have the following installed:

- **.NET SDK 10.0+** (used as a background build tool, never shipped to runtime)
- **Node.js 22+** or **Bun 1.3+**
- Your preferred package manager: **bun**, **pnpm**, or **npm**
- **Cloudflare CLI (`cf`)** or Wrangler

---

## 1. Scaffold a New Project

Initialize a fullstack monorepo with React 19, Tailwind CSS v4, shadcn/ui, Better Auth, and an end-to-end type-safe C# backend:

## 2. Project Composition (`apps/api/app.cs`)

Your entire application entry point is configured in `app.cs`:

```csharp
var authOptions = new AuthOptions
{
    CookieName = "better-auth.session_token",
};

// Wire optional OAuth providers
var googleClientId = Environment.GetEnvironmentVariable("GOOGLE_CLIENT_ID");
var googleClientSecret = Environment.GetEnvironmentVariable("GOOGLE_CLIENT_SECRET");
if (!string.IsNullOrEmpty(googleClientId))
{
    authOptions.WithGoogle(googleClientId, googleClientSecret!);
}

var app = ReptarApp.Create(new ReptarConfig
{
    Auth = authOptions,
    Database = Db.D1(), // or Db.Sqlite() / Db.Postgres() / Db.MySql()
});

app.Use(RequestId());
app.Use(Telemetry());
app.Use(Cors());

// Mount Better Auth endpoints under /api/auth
var authGroup = app.Group("/api/auth");
BetterAuthProtocol.Routes(authGroup, authOptions);

// Mount business features
ItemsFeature.Configure(app);

await app.EnsureCreatedAsync();
await app.RunAsync(args);
```

## 3. Local Development

Run the fullstack development environment:

```bash
bun run dev
```

This starts:

- The React 19 frontend at `http://localhost:5173`
- The Reptar C# API backend at `http://localhost:8787`
- The Better Auth protocol endpoints at `http://localhost:8787/api/auth`

---

## 4. End-to-End Type Safety & Codegen

When you add or update routes in C#, generate updated TypeScript contracts:

```bash
bun run api:codegen
```

This compiles your C# route tree and updates `packages/client/src/` with strongly-typed interfaces, endpoint contracts, and Zod schemas.

---

## 5. Consume from the Frontend

Your frontend is already wired with the generated typed client and Better Auth:

```tsx
import { client } from "@/lib/client";
import { authClient, useSession } from "@/lib/auth-client";

export function Dashboard() {
  const { data: session } = useSession();

  // 100% type-safe RPC call generated from C#
  const res = await client.api.items.get();
  if (res.ok) {
    const items = await res.json();
    console.log("Items:", items);
  }
}
```
