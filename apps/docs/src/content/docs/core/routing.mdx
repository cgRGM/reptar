## Route Parameters, Query Strings & Groups

Access path parameters, query strings, and headers directly from `ctx.Req`, and organize related endpoints with `app.Group(...)`:

```csharp
var api = app.Group("/api/v1");

api.Get("/tasks/:id", async ctx =>
{
    var id = ctx.Req.Param("id");
    var includeComments = ctx.Req.QueryValue("comments", defaultValue: "false");
    var authorization = ctx.Req.Header("Authorization");

    var task = await ctx.Db.QuerySingleOrDefaultAsync<TaskItem>(
        "SELECT id, title, status FROM tasks WHERE id = @id",
        ("id", id));

    return task is null ? ctx.NotFound() : ctx.Json(task);
});
```

## Explicit Contracts & OpenAPI 3.1 Metadata

Every route builder supports fluent contract and OpenAPI 3.1 metadata methods:

```csharp
app.Post("/api/tasks", CreateTaskValidator, async (ctx, input) =>
{
    // ...
    return ctx.Json(created, 201);
})
    .WithSummary("Create a task")
    .WithDescription("Validates input constraints and inserts a new task record.")
    .WithTags("Tasks")
    .Produces<TaskItem>(201)
    .Produces<ValidationError>(400);
```

- **`.Produces<T>(status)`**: Declares exact response types per status code for both `@reptar/client` TypeScript RPC codegen and OpenAPI 3.1 responses.
- **`.WithSummary()` / `.WithDescription()` / `.WithTags()`**: Populates the zero-reflection OpenAPI 3.1 specification.
- **Interactive UI**: Call `app.UseScalar()` to serve `/openapi.json` and interactive Scalar documentation at `/reference`, or `app.UseSwaggerUi()` to serve Swagger UI at `/swagger`.

## Server-Sent Events (SSE) for AI & Real-Time Streaming

Reptar includes native, zero-allocation Server-Sent Events (`ctx.Sse`) backed by `System.Threading.Channels.Channel<byte[]>`. Chunks stream directly into Kestrel's `PipeWriter` with automatic `FlushAsync()` and proxy-buffering disabled (`X-Accel-Buffering: no`):

```csharp
app.Get("/api/ai/chat", ctx =>
{
    return Task.FromResult(ctx.Sse(async stream =>
    {
        await stream.SendAsync("Connecting to model...", @event: "status");
        await stream.SendJsonAsync(new { token = "Hello " }, @event: "delta", id: "tok_1");
        await stream.SendJsonAsync(new { token = "world!" }, @event: "delta", id: "tok_2");
        await stream.SendAsync("[DONE]", @event: "done");
    }));
});
```

## Perimeter Stale-While-Revalidate (`CacheControl.SWR`)

For read-heavy endpoints, `CacheControl.SWR` caches anonymous `GET` responses in memory, serves warm hits in **2.6–3.3 ms p50** (up to **39,214 req/s**), refreshes stale entries asynchronously in the background, and automatically invalidates affected routes on mutating writes (`POST`, `PUT`, `PATCH`, `DELETE`):

```csharp
// Serve fresh from memory for 15s; serve stale for up to 30s while revalidating in background
app.Use(CacheControl.SWR(ttlSeconds: 15, swrSeconds: 30));
```

## Sliding-Window Rate Limiting

`RateLimit.SlidingWindow` uses an O(1) atomic weighted sliding-window counter without timestamp list allocations and emits standard IETF rate-limit headers (`X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`, and `Retry-After` on `429`):

```csharp
// Allow 60 requests per 60-second sliding window per client IP
app.Use(RateLimit.SlidingWindow(limit: 60, windowSeconds: 60));
```

## Production Ergonomics: Health Probes, Security Headers & Static SPA Serving

Reptar ships zero-config helpers for container and edge production deployments:

```csharp
// 1. Liveness (/health/live) & DB Readiness (/health/ready with SELECT 1 probe)
app.MapHealth();

// 2. OWASP Security Headers (nosniff, DENY, HSTS, Referrer-Policy, Permissions-Policy, CSP)
app.UseSecurityHeaders(opts =>
{
    opts.ContentSecurityPolicy = "default-src 'self'";
});

// 3. Static Asset Serving with ETag (304 Not Modified), Immutable Asset Caching & SPA Fallback
app.UseStaticFiles("wwwroot");
```
