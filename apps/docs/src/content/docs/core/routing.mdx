## Route Parameters & Query Strings

Access path parameters and query strings directly from `ctx.Req`:

```csharp
// Path parameters
var id = ctx.Req.Param("id");

// Query string values
var page = ctx.Req.Query("page", defaultValue: "1");

// Headers
var authorization = ctx.Req.Header("Authorization");
```

## Explicit Contracts with `.Produces<T>()`

`.Produces<T>(status)` is the core mechanism that connects C# route handlers to frontend TypeScript types and OpenAPI schemas:

- **Type safety:** Tells the codegen engine the exact return type for status code `200`, `201`, `404`, etc.
- **Client accuracy:** Generated RPC clients type the return value of `await api.posts.$get()` based entirely on `.Produces<T>()`.
- **Zero guesswork:** If a route produces different models on success versus error, both are explicitly declared.
