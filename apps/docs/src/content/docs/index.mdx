Reptar is a C# web framework built from first principles for **Cloudflare Workers (`netwasm0.1`)** and **Linux Native AOT (`net10.0`)**. It combines Hono-style routing, Drizzle-style table schemas, compile-time `[ReptarEntity]` row mapping, auto-derived OpenAPI 3.1 specifications, and end-to-end TypeScript RPC client generation—with zero runtime reflection.

```csharp
var app = ReptarApp.Create(new ReptarConfig
{
    Database = Db.D1(), // or Db.Sqlite("app.db"), Db.Postgres(url), Db.MySql(url)
});

app.Use(CacheControl.SWR(ttlSeconds: 15, swrSeconds: 30));
app.Use(RateLimit.SlidingWindow(limit: 120, windowSeconds: 60));
app.UseScalar(title: "My Reptar API");

app.Get("/tasks/:id", async c =>
{
    var task = await c.Db.QuerySingleOrDefaultAsync<TaskItem>(
        "SELECT id, title, status FROM tasks WHERE id = @id",
        ("id", c.Req.Param("id")));
    return task is null ? c.NotFound() : c.Json(task);
}).Produces<TaskItem>(200);

await app.RunAsync(args);
```

## Core Capabilities

<CardGrid>
  <Card title="Dual-Target Wasm & Native AOT" icon="rocket">
    Compile the same C# feature slices to WebAssembly for Cloudflare Workers (&lt;2 ms warm execution) or a **10.4 MB** standalone Linux Native AOT binary (`-p:ReptarSqliteOnly=true`) that boots in 124 ms.
  </Card>
  <Card title="Zero-Reflection Data Layer" icon="seti:db">
    Decorate records with `[ReptarEntity]` to emit compile-time positional `DbDataReader` mappers and `ColumnRef<T>` query tokens. Query D1, SQLite (synchronous WAL read pool + group-commit batcher), PostgreSQL (`NpgsqlBatch`), and MySQL with zero reflection.
  </Card>
  <Card title="OpenAPI 3.1, SSE & SWR Cache" icon="open-book">
    `Rule<T>()` validators automatically populate OpenAPI 3.1 JSON Schemas served via Scalar UI (`/reference`). Stream AI responses over zero-alloc `ctx.Sse(...)` channels and serve reads at 39k+ req/s with `CacheControl.SWR`.
  </Card>
  <Card title="Typed RPC & Better Auth" icon="approve-check">
    Generate zero-dependency `@reptar/client` TypeScript RPC proxies and `~standard` validators directly from `.Produces<T>()`. Authenticate with built-in C# `Reptar.Auth` or the wire-compatible Better Auth protocol.
  </Card>
</CardGrid>
