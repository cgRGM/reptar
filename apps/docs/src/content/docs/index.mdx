## Architectural Foundations

<CardGrid stagger>
  <Card title="The One Rule" icon="seti:c-sharp">
    Reptar is strictly the backend. The only frontend-facing surface is generated contracts: typed fetch client, Standard Schema, and OpenAPI.
  </Card>
  <Card title="Compiled WebAssembly" icon="rocket">
    Your C# compiles to NetWasm and Native AOT. Zero runtime reflection; the Wasm instance is cached per isolate.
  </Card>
  <Card title="D1, R2 & AI Bindings" icon="cloud">
    First-class platform surfaces exposed directly as C# APIs through `c.Db`, `c.Storage`, `c.AI`, and `c.RateLimit`.
  </Card>
  <Card title="Zero-Dep Validation" icon="approve-check">
    `Rule<T>` validates inputs on the backend and emits zero-dependency `~standard` validators for TanStack Form or Zod.
  </Card>
</CardGrid>
