## Generated Artifacts

`bun reptar codegen` inspects your C# feature slices and outputs:

```text
packages/rpc/src/
  app-type.d.ts           # Complete route tree type: AppType
  types.ts                # TypeScript DTO interfaces corresponding to C# records
  schemas.generated.ts    # Zero-dependency Standard Schema validators (~standard)
  client.ts               # Stable, ~100-line createClient runtime

packages/contract/
  reptar.spec.json        # Language-neutral schema for multi-platform client generators
  openapi.json            # Standard OpenAPI 3.1 specification
```

## Consuming the Typed Client

The `@reptar/client` package provides a minimal (~100 lines), zero-dependency proxy client that provides full type inference for route segments, URL parameters, query strings, and request/response bodies:

```typescript
import { createClient } from "@reptar/client";
import type { AppType } from "./app-type";

// 1. Browser Client (includes cookies across requests)
export const api = createClient<AppType>(
  "https://reptar-api.rocktown-labs.workers.dev",
  {
    credentials: "include",
  }
);

// Calling endpoints with full autocomplete:
const postsResponse = await api.posts.$get();
if (postsResponse.ok) {
  const posts = await postsResponse.json(); // Typed as Post[]
}

// 2. Server-Side Rendering via Cloudflare Worker Service Binding (Zero Network Overhead)
export const ssrApi = createClient<AppType>("http://internal", {
  fetch: env.API.fetch.bind(env.API),
});
```

## Zero-Dependency Standard Schema

Every `Rule<T>` in your C# backend generates a validator implementing `~standard` (version 1, vendor `"reptar"`).

```ts
import { createPostSchema } from "@reptar/rpc";
import { useForm } from "@tanstack/react-form";

// Plug directly into TanStack Form with zero additional validation packages
const form = useForm({
  validatorAdapter: createPostSchema,
  defaultValues: {
    title: "",
    content: "",
  },
});
```

One `Rule<T>` in C# provides:

1. Server-side validation
2. Client-side form validation
3. TypeScript static types
4. OpenAPI schema constraints
