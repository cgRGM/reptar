title: Contact
description: How to reach the Reptar project.
---

Reptar is developed in the open on GitHub — that's where all project communication happens.

- **Bug reports and feature requests:** [open an issue](https://github.com/RocktownLabs/reptar/issues) in the repository. Include the CLI doctor output (`bun reptar doctor --json`) and the output of `bun reptar inspect --json` when reporting framework problems — machine-readable state makes issues reproducible.
- **Questions about the framework:** the documentation is the first stop. Start with [Why Reptar](/overview/why-reptar/) or the [quick start](/getting-started/quickstart/).
- **Building with AI agents:** the [Build with an AI Agent](/getting-started/agents/) guide is written to be handed to a coding agent directly. The repository also ships a canonical agent reference at [`llms.txt`](https://github.com/RocktownLabs/reptar/blob/main/llms.txt) and an installable [agent skill](https://github.com/RocktownLabs/reptar/blob/main/packages/rpc/skills/reptar/SKILL.md) for agents working in Reptar codebases.

There is no support email yet — the project is early and deliberately small, and keeping every conversation on GitHub makes it public, searchable, and answerable once for everyone.
