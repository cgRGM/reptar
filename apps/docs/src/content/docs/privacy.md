---
title: Privacy
description: "What this documentation site collects (spoiler: nothing)."
---

This is a static documentation site, built with [Astro Starlight](https://starlight.astro.build/) and served from [Cloudflare](https://www.cloudflare.com/). It contains no analytics, no advertising, no cookies, and no third-party trackers.

The only thing stored on your device is a theme preference (light or dark mode), kept in your browser's `localStorage` by Starlight's theme switcher. It never leaves your browser.

- **No accounts, no sign-in.** The docs are entirely public.
- **No personal data.** Nothing is collected, processed, or shared.
- **Edge logs.** As with any hosted site, Cloudflare processes request logs at the edge for operational purposes. We don't retain or analyze them ourselves.
- **Everything is inspectable.** The full contents of this site live in the open repository — [cgRGM/reptar](https://github.com/cgRGM/reptar), under `apps/docs/`.

If any of this ever changes, this page will say so first.
