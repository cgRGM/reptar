Reptar includes a high-performance **AI Gateway** pattern (`examples/ai-gateway`) capable of proxying, caching, and load-balancing traffic across OpenAI, OpenRouter, Anthropic, Gemini, Groq, Ollama, and Cloudflare Workers AI.

It is 100% wire-compatible with both standard Server-Sent Events (SSE) and the **Vercel AI SDK Data Stream Protocol**, so React, Next.js, and Vite clients using `useChat()` can connect directly with zero client-side adapters.

---

## Architecture & Features

1. **Universal Model Proxy (`POST /v1/chat/completions`)**:
   Accepts standard OpenAI-compatible JSON payloads and transparently converts requests and streaming responses for the destination provider.

2. **In-Connection Failover**:
   If the primary provider returns `429 Too Many Requests` or `5xx Server Error`, the gateway automatically retries the next configured fallback provider in the same HTTP connection before any tokens are streamed to the client.

3. **Dual Wire Protocols**:
   - **Standard SSE**: `Accept: text/event-stream` returns OpenAI-compatible `data: {"choices":[{"delta":{"content":"..."}}]}` stream.
   - **Vercel Data Stream**: `Accept: text/vnd.ai` or `?stream_protocol=data-stream` returns `0:"token"` text deltas and `d:{"finishReason","usage"}` payloads for `useChat()`.
   - **Buffered JSON**: `"stream": false` returns standard OpenAI `chat.completion` objects.

4. **SHA-256 Prompt Cache**:
   Keyed on `SHA-256(model + messages)`. Cache hits replay the token stream at sub-millisecond latencies with `X-Reptar-Cache: HIT`, dramatically cutting upstream token costs.

5. **Fire-and-Forget SQLite Telemetry**:
   Token counts, latencies, and cache metrics are written via Reptar's SQLite group-commit channel batcher, ensuring persistence never stalls response throughput.

```bash
# Start local gateway on port 8788
bun gateway:dev

# Run 500-connection streaming benchmark
bun gateway:bench
```
